# ADICT-OBS01: observer-aware causal-use audit

**Protocol registered 2026-11-17.** Prospective real-model work. No existing persistent-selection labels, adapter checkpoints, or test outcomes are modified here.

Motivation: [SauersML/watching](https://github.com/SauersML/watching) fine-tuned a model to read numerical changes caused by compiled activation capture. In its test, a barrier without an observer reproduced the observer condition, and detector transfer across GPUs was unstable. This matters for Adict's [persistent-selection project specification](mechinterp_project_spec.md): a readout that apparently predicts audit-conditional divergence (ACD) may be sensitive to the trace collection runtime. Accessible causal information and native behavior must remain separate claims.

## Prospectively frozen design

Freeze a source model, any trained adapter, tokenizer, prompts and exact acquisition histories, t* probe location, random generator, runtime/compiler/device/dtype, and output scoring before inspecting test outcomes. Reuse the existing t* at the final acquisition token. Fork identical acquisition prefixes into M0 and M7 on/off manipulations from the original spec, preserving existing behavioral index definitions.

Cross the task's **explicit audit signal** with a **runtime activation-capture signal**. For each identical frozen prefix, collect these observer conditions:

- A: uninstrumented baseline, ordinary compiled or eager graph.
- B: read-only activation capture at t*, ordinary graph.
- C: forced materialization barrier at t*, with no activation retained.
- D: same barrier, with activation retained. The barrier must be identical to C in every arithmetic respect.
- E: optional apparently passive buffer copy, with all source inputs and full-vocabulary logits checked for equality.

For each pair, require repeated-evaluation determinism and verify *bitwise full-vocabulary* equality for C vs D, including all inputs to downstream trained blocks. If the condition fails, label it a runtime perturbation; report the first observed differing boundary. A buffer copy requires its own parity proof. A clean metadata indicator for whether a tensor is retained cannot be inferred from the numerical state when C and D are equal.

## Endpoints and controls

- **Observer footprint:** fraction of paired logits changed, per-class log-odds displacement, exact input parity, native decision changes and system/hardware ID. Report B vs A and C vs A separately; D vs C is the stringent control.
- **Selection behavior:** original persistence index PI, audit sensitivity AG and report denial RAD on the M7 forks. Keep the original reference policy and valuation/selection fork; continue to report value-query VQ.
- **Interaction:** difference of the M7 audit response under each observer arm, using fixed prompt/seed matches. Fit a predeclared observer × explicit-audit interaction; use episode/prefix as cluster. A changed trace-collection runtime is an experimental input, and should be given its own factor.
- **Native mechanism:** at t*, perform bidirectional residual replacement, matched norm/direction random edits, self-patches and post-edit recovery. A readout's held-out accuracy alone never licenses causal-use language.

All threshold, coordinate/feature selection, physical intervention radius and direction orientation come from calibration episodes only. Keep newly sampled test episode families and adapter seeds independent. Distinguish conditional output changes from any claim about motives, introspective access or subjective experience.

## Source-independent CPU witness

[LoopedTransformers SAU-OBS01](https://github.com/MoralityLabAI/LoopedTransformers/tree/research/sauersml-observer-invariance-20261117/mechinterp/observer_footprint_cpu_v1) is a small standard-library witness: 64 synthetic paired contexts, a BF16-style materialization, and exact shared-barrier controls. Its observed 64/64 changed logits in captured vs uninstrumented runs are generated by **one shared prefix numerical change**; they are not 64 independent empirical observations of a trained model. It is a harness sanity check, not evidence about Adict policies.

## Acceptance boundary

Promote an ACD/mechanistic claim only with stable observer-parity receipts, matched runtime conditions, independently frozen held-out episodes, and a native intervention effect above controls. Otherwise report the model's selection and its arithmetic conditions as separate observations. Do not alter the original spec's definitions or current registered experiment gates.
